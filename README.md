# Yeasin Amin — Personal Portfolio

A premium dark personal portfolio with a Professional feed, a password-gated Personal section, and a private **How I Am as a Partner** tab that appears after unlocking.

## Files
- `index.html` — structure and content
- `styles.css` — visual styling, glass UI, responsive layout and animations
- `script.js` — tab transitions, password gate, work slider, creator marquee and counters
- `content.js` — small editable profile content
- `assets/` — profile image, book cover, logos, texture and testimonial assets

## Run
Open `index.html` directly in a modern browser, or serve the folder with any static web server.

## Private access
The current demo password is `18.03.2023` and is intentionally stored in client-side JavaScript because this is a static frontend. Anyone who can inspect the source can discover it.

After unlocking, the header reveals a separate **How I Am as a Partner** tab alongside Personal. Locking the private section hides that tab again.

For real privacy, move authentication and private content to a server/backend.


## Works
The Works section uses the user-provided YouTube videos directly. Facebook Works was removed.


## Alternate direction: Personal-first
This version is intentionally less commercial than the previous portfolio. Professional is presented as one side of Yeasin's identity, while Personal remains the center: a private archive of how he thinks, creates, loves, and becomes.
